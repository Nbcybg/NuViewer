## What would flip a no

- If PSD and AI files with transparency showed exactly like in Photoshop/Illustrator, with colour-managed accuracy I can verify on my own files, and a pure viewing mode that hides the editor, gallery and everything else.
- Proof that it reads and writes XMP/metadata without breaking existing sidecars, plus a side-by-side showing my TGA/DDS/EXR files render the same as in XnView MP, and a few months of updates that show the developer is sticking with it.
- Open source code, or at least a code-signed installer with a clear changelog. Plus a month of it handling my big cbz folders with no crashes and no memory bloat.
- A code-signed installer or published source code, and my own stopwatch test with my PNG/PSD exports showing it really is faster than Photos.
- A signed installer, public source code or a clean independent scan, and a clearly pure-viewer mode with the same full-screen behaviour as FastStone.
- Proof that it reads XMP ratings and labels without writing to my files, and that its colour output matches Photoshop on my own ICC files. A few months of stable releases would help too.
- A code-signed installer, source on GitHub, and several independent reviews or photographer friends I trust using it. It would also need a real RAW+JPG culling feature, such as pick/reject marks or side-by-side compare, and not just speed.
- A few months of stable releases and visible bug fixes, plus proof that my XMP/sidecar ratings and colour setup survive a cull untouched. Being able to rate or tag and reject in the viewer, with the RAW+JPG pair handled sanely, would make me look seriously.
- If it opened my own DDS/TGA/EXR/GLB files correctly on the first try, and a cbz opened as a page-by-page reader with arrow keys. Then I'd set it as default for those formats.
- Published source code or a code-signed installer, plus a few independent reviews from other artists showing it handles RAW+JPG culling and PSD alpha correctly over a few months.
- A signed installer, or open source I can check, plus a clean test on my own RAW+JPG shoots where it stays as fast as the benchmark says and doesn't misread colour.
- If it were noticeably faster than ImageGlass on my own 500 RAW+JPG card and had an option to treat each RAW+JPG pair as one shot so culling doesn't double, and had been stable for a year or two with other people using it.
