NuViewer 0.4.1: a free image viewer for Windows 10/11 made by one developer. Download an installer (per-user, no admin rights) or a portable zip. There is a "buy me a coffee" support link in its credits; nothing is locked.
Measured on the developer's own screen-timing benchmark against IrfanView, ImageGlass, FastStone and Image Simple Viewer (one PC, 2560x1440): opens a typical JPG/PNG in about 120-350 ms, next/back about 40-50 ms per picture, rapid next x5 about 85 ms vs 600-900 ms for FastStone/IrfanView. Opened 26 of 32 test file types (FastStone 19, ImageGlass 17, IrfanView 13). It was slower on one damaged-JPEG file and tied with IrfanView on some PSD/TGA files.
Opens photos, camera RAW (developed from sensor data, or the embedded preview), PSD, AVIF, WebP, JPEG XL, HDR/EXR/TGA/DDS, PDF/AI/SVG, 3D models (GLB/OBJ/STL/FBX), video and audio, zip/cbz/7z archives. RAW and JPG of the same shot always show as separate pictures.
Comes with a gallery (thumbnail grid, folder tree, batch rename/convert), a quick Space-bar preview from Explorer, an editor (white balance, curves, heal, presets, sidecar edit file) and a screenshot/scanner importer. Colour management with ICC profiles.
Limits: Windows only; version 0.4.1 from a single developer; no plug-in system; the interface text is English (a Thai starter file exists); some formats (SAI, 3MF, Max, DUF, MID) show an error panel; HEIC needs Microsoft's HEVC extension; Windows will not let any app make itself default silently, so you tick the formats and press "Set default" yourself in Windows Settings.
